Admin / API Settings

ตั้งค่าการเชื่อมต่อ API สำหรับผู้พัฒนาและเจ้าของแอป

ข้อควรระวังความปลอดภัย: ในระบบจริง (Production) ควรตั้งค่า API Key ไว้ที่ Backend Server / Environment Variable เท่านั้น ไม่ควรฝัง Secret Key ลงใน Client-side HTML/JS

1. ตั้งค่า Local Browser API Key (สำหรับทดสอบ Client-Side)

คุณสามารถบันทึก Key ลงใน LocalStorage ของเบราว์เซอร์เครื่องนี้เพื่อใช้ทดสอบการดึงข้อมูลชั่วคราวได้

รับ Key ได้จาก Google Cloud Console (เปิดใช้งาน YouTube Data API v3)
รับ Key ได้จาก TikTok Developers Portal

2. การตั้งค่า Backend Proxy URL (สำหรับระบบ Production)

เซิร์ฟเวอร์ฝั่ง Node.js / Python / Go ที่ทำหน้าที่ซ่อน API Key และจัดการ OAuth Access Token

คำแนะนำขั้นตอนการขอ API Key
